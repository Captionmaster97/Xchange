# Campus Xchange — The Student Skill Economy

A student-to-student skill exchange prototype. Students teach something they know and earn time credits they can spend learning from someone else. No money changes hands: one hour of teaching earns one hour of learning credit.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy
Upload the contents of this folder to a GitHub repository and import it into Vercel. Framework preset: Next.js. No environment variables required.

## Prototype scope
This is a frontend prototype with sample listings and localStorage persistence. Booking/offer actions are simulated. Real student verification, messaging, session scheduling, credit ledger integrity, notifications and moderation require a backend.
